# A7M Dashbord

إضافة سطح مكتب لهيرمز: ترحيب يتكوّن من رموز، ثم لوحة كانبان للعرض فقط بثيم Terminal من Hallmark.

## ما تعرضه

- العبارة `Welcome to Hermes Dashbord` بحروف كبيرة مكوّنة من رموز؛ دخول تلقائي بعد 2.4 ثانية عند فتح الصفحة. إعداد تقليل الحركة يتجاوز المقدمة.
- حالات كانبان الأصلية كما يرسلها هيرمز، دون قاعدة مهام منفصلة.
- عدد المهام الجارية والمتوقفة والإجمالي، والمسؤولون عن المهام الجارية.
- اتصال الواجهة والنموذج والملف الشخصي، ووقت آخر قراءة ناجحة.
- تفاصيل المهمة وآخر ملخص تشغيل متاح، وقد يعود إلى تشغيل سابق. لا توجد نسب تقدم تقديرية.
- تحديث كل عشر ثوانٍ عندما تكون الصفحة نشطة، مع تحديث يدوي وحالات تحميل/فراغ/خطأ واضحة.

لا تنشئ الإضافة مهام ولا تحركها ولا تشغّل وكلاء. عدّ المسؤولين عن المهام الجارية ليس رصدًا لحياة عمليات الوكلاء. للتعديل استخدم Kanban الأصلي.

## دليل الموديلات

تبويب مستقل للبحث والمقارنة في كتالوج OpenRouter العام: أسعار الإدخال والإخراج بالدولار لكل مليون توكن، طول السياق، وصف المزوّد، ودعم النص/الصور/الصوت والأدوات والاستدلال حسب البيانات المنشورة. لا يدّعي أن جميع هذه الموديلات متاحة في حساب Nous، ولا أن أسعار API هي فاتورة الاشتراك.

حاسبة التكلفة تقدّر رموز الإدخال غير المخزنة والإخراج والإدخال المخزن كأعداد منفصلة، ولا تضم رسوم الوسائط أو الطلبات أو الأدوات. السعر المفقود يظهر غير متاح، وليس صفرًا. الكتالوج يُقرأ من مصدر HTTPS ثابت، يُخزّن مؤقتًا في الذاكرة، ويظهر تاريخ القراءة وتحذير عند استخدام بيانات قديمة. لا تُرسل بيانات المهام للمصدر العام.

## التركيب

تحتاج الإضافة جزأين لأن `ctx.rest` مقيد بمساحة الإضافة، ونسخة الخادم التي فُحصت لا توفر RPC لقراءة كانبان.

### الخادم

حزمة Hermes أصلية باسم `a7m-dashboard` مع واجهة GET فقط في `dashboard/plugin_api.py`. تقرأ قاعدة كانبان الموجودة باتصال SQLite `mode=ro` و`query_only`؛ لا تنشئ قواعد ولا تجري migrations. يلزم تفعيل حزمة الخادم لتصبح `/api/plugins/a7m-dashboard/snapshot` متاحة عبر مصادقة هيرمز المعتادة.

### تطبيق Windows

من **Capabilities → Plugins → Install from Git** اختر المستودع:

`https://github.com/a7madxz6/hermes-Dashbord`

اختر هدف **Desktop** إن ظهر، وفعّل الإضافة. المستودع خاص، لذلك يحتاج تطبيق جهازك صلاحية قراءته؛ تسجيل دخول الخادم لا يسجّل دخول Windows تلقائيًا. إذا تعارضت النسخة اليدوية القديمة، احتفظ بنسخة احتياطية خارج مجلد `desktop-plugins` قبل إزالتها أو استبدالها.

بديل يدوي: ضع الملف المبني `plugin.js` داخل:

```text
C:\Users\a7reb\AppData\Local\hermes\desktop-plugins\a7m-dashboard\plugin.js
```

ثم أعد تحميل إضافات سطح المكتب. رفع commit إلى GitHub وحده لا يحدّث الملف المحلي.

## التطوير

```sh
npm ci --ignore-scripts
npm run build
npm test
npm run test:browser
```

لا يحتوي ملف التشغيل على React مستقل أو اعتماد على Node؛ يستورد نسخة React وSDK من التطبيق. أدوات الاختبار والبناء فقط تستخدم حزم npm.

اختبارات الواجهة تستخدم SDK بديلًا وبيانات fixtures معلّمة للاختبار؛ نجاحها لا يثبت تحميل الإضافة في نسخة Windows. الصور الموجودة في artifacts محلية ومهملة من Git وليست بيانات إنتاج.

## الخصوصية

لا مفاتيح API أو توكنات داخل البلوقين. لا طلبات لخدمات تحليل أو خطوط بعيدة. كل طلب بيانات يمر عبر اتصال هيرمز المصادق عليه. التطبيق للعرض فقط، والخادم لا يصدّر مسارات الملفات أو بيانات الاعتماد.
